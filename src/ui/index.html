How files are used

  • PDF, Word, ODT, TXT, Markdown, HTML: plain text, the model learns to continue it.
  • CSV, TSV, Excel, XML, JSON: columns like question/answer, instruction/input/output or prompt/response become chat examples. Other tables are used as text.
  • JSON/JSONL with messages (OpenAI / ShareGPT format) are used as conversations.
